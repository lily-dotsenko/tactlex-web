# ТактЛекс: вимоги до MVP

## Призначення

ТактЛекс — безплатний двомовний вебтренажер військової англійської. Користувач вивчає перевірені терміни короткими уроками, практикує переклад у двох напрямках, повертається до складних слів за розкладом повторень і бачить підтверджений сервером прогрес.

Слоган: **«Тренуй слова. Розумій команди».**

Пріоритетна аудиторія — військовослужбовці й курсанти. Застосунок так само доступний волонтерам, цивільним та іншим охочим. Необов’язковий тип профілю (`military`, `civilian`, `cadet`, `volunteer`, `other`, `prefer_not_to_say`) приватний за замовчуванням і не впливає на функції.

ТактЛекс є мовним тренажером, а не заміною сертифікованому медичному чи військовому навчанню. У контенті не допускаються секретні, чутливі чи оперативні інструкції щодо зброї, вибухових пристроїв або ведення бойових дій.

## Результат MVP

MVP надає завершений технічний контур для 616 навчальних термінів у 77 уроках п’яти категорій. Усі записи входять до відкритої навчальної стежки; перший публічний пакет має видиму beta-позначку до предметної перевірки:

| Категорія                    | Цільова кількість |
| ---------------------------- | ----------------: |
| Базова військова англійська  |               100 |
| Загальна тактична англійська |                60 |
| Тактична медицина / TCCC     |                50 |
| Дрони та UAS                 |                50 |
| Снайперська термінологія     |                40 |

Усі імпортовані записи спочатку отримують статус `DRAFT`. Дозволений власником тимчасовий beta-реліз не створює фальшивих даних рецензента: неперевірені записи мають явну позначку, а звичайна публікація й надалі потребує предметної перевірки.

## Функціональний обсяг

### Відвідувач

- бачить українську або англійську landing page;
- перемикає мову;
- реєструється за email і паролем;
- входить у наявний обліковий запис.

### Користувач

- завершує onboarding і налаштовує приватність рейтингу, nickname, денну ціль і бажані категорії;
- переглядає dashboard, категорії, опублікований словник та сторінки термінів;
- проходить урок на 6–12 термінів: ознайомлення, практика, After Action Review;
- виконує вправи EN → UA та UA → EN, а сервер перевіряє відповідь;
- оцінює повторення як Again, Hard, Good або Easy;
- бачить чергу повторень, прогрес, XP, streak, рівень і досягнення;
- переглядає weekly та all-time leaderboard, де відображається лише nickname;
- приховує себе з рейтингу;
- слухає людський запис або явно позначене синтетичне озвучення;
- повідомляє про проблему в терміні;
- виходить із системи й керує профілем.

### Адміністратор

- має всі можливості користувача;
- керує категоріями, уроками, термінами, варіантами, визначеннями, джерелами та аудіо;
- імпортує CSV виключно у `DRAFT`;
- переводить контент через `DRAFT → IN_REVIEW → APPROVED → PUBLISHED → ARCHIVED`;
- не може опублікувати неповний термін без перевіреного джерела;
- керує користувачами й дозволеними ролями;
- переглядає reports та незмінний audit log;
- налаштовує досягнення.

## Навчальні правила

- правильні відповіді та дозволені синоніми зберігаються на сервері й не надсилаються клієнту до оцінювання;
- нормалізація охоплює регістр, повторні пробіли, Unicode, українські апострофи та явно затверджені варіанти дефісів;
- нечітке порівняння, яке може прийняти інший за значенням термін, не використовується;
- scheduler сумісний із принципами FSRS і зберігає state, difficulty, stability, due date та кожний перехід;
- XP, streak, рівень, досягнення та місце в рейтингу обчислюються лише на сервері;
- завершення уроку, прогрес, XP і нові нагороди фіксуються транзакційно та ідемпотентно.

## Інформаційна архітектура

Публічні сторінки: landing, реєстрація, вхід.

Користувацькі сторінки: onboarding, dashboard, навчання, категорії, урок, вправа, результат, повторення, словник, термін, прогрес, досягнення, рейтинг, профіль, налаштування.

Адміністративні сторінки: overview, терміни, перевірки, категорії, уроки, користувачі, reports, досягнення, audit log.

Основна мобільна навігація: Головна, Навчання, Повторення, Словник, Профіль.

## Якість інтерфейсу

- українська — основна мова, `uk` і `en` підтримуються для UI та контенту;
- мобільна верстка працює від 360 px;
- світла й темна теми;
- WCAG AA, передбачуваний порядок фокусу, помітні focus states, семантична розмітка та touch targets не менші за 44×44 px;
- графітова основа, стриманий оливковий, синій і теплий жовтий акценти, делікатна українська геометрія;
- без надмірного камуфляжу, бойових фотографій та офіційних емблем ЗСУ, НАТО чи підрозділів.

## Поза MVP

- Android, React Native, Expo і будь-який мобільний клієнт;
- зовнішнє розгортання та production cloud infrastructure;
- OAuth/social login, MFA та реальна email-доставка для verification/reset;
- повноцінне offline-навчання або локальна черга відповідей;
- автоматичне AI-затвердження контенту;
- звичайна публікація неперевірених перекладів без явного beta-режиму;
- production S3 bucket — реалізується лише adapter contract;
- нові тематичні категорії поза п’ятьма стартовими.

## Ризики та рішення

1. **Контентна готовність залежить від експерта.** Код, importer і workflow завершуються автономно; неперевірений контент лишається `DRAFT`.
2. **Складні PostgreSQL constraints не виражаються Prisma DSL.** Extensions, check constraints, partial/trigram indexes та append-only triggers зберігаються в контрольованій SQL migration.
3. **Cookie-auth не є остаточною моделлю для mobile.** Доменні services приймають ідентичність окремо від HTTP cookie adapter, тому майбутній bearer adapter не змінить бізнес-правила.
4. **PWA може спричинити застарілі приватні дані.** Service worker кешує лише shell і статичні assets; API та mutations використовують network-only.
5. **Filesystem audio не підходить кожному production runtime.** Storage interface має local і S3-compatible реалізації; локальна реалізація призначена для MVP та self-hosting.

## Критерії приймання

Definition of Done є фінальним gate: успішний build, clean migrations, повторний seed, дві локалі й два напрямки навчання, п’ять категорій, 616 термінів у 77 уроках, 77 текстових квізах, 41 факті, 217 вузлах, коректний workflow, server-side auth/RBAC/answers/XP/rewards, PostgreSQL progress і review queue, одноразові нагороди, ліги, PWA, критичні тести, актуальна документація, відсутність секретів, логічні коміти й підтверджений push у `lily-dotsenko/tactlex-web`.
